# Supply Chain Disruption Prediction Agent (Infothon 7.0 MVP)

Synthetic-data demo: Sense -> Predict -> Trace + plan -> Approve.

## Run it
1. pip install -r requirements.txt
2. python data/generate_synthetic.py        (creates supply.db)
3. streamlit run app/streamlit_app.py       (opens http://localhost:8501)

All figures come from synthetic data - they prove the pipeline works, not real-world accuracy.
